# 学习记录

关注三个相互连接的方向：建筑设计判断、AI 工具使用、建模与表达。

## 新建一条记录

复制 [TEMPLATE.md](TEMPLATE.md)，命名为 `YYYY-MM-DD-topic.md`；也可以在仓库根目录运行：

```bash
python scripts/new_note.py --topic entrance-study
```

Windows 也可使用 `py -3` 替代 `python`。脚本只创建新文件，不覆盖已有记录。

## 可选的小实验

- 建筑：用同一张平面比较两种入口或流线表达，解释取舍。
- AI：保持输入图片不变，每次只修改一个提示词条件，对照结果。
- 建模：练习一个体块、组件或材质组织方法，记录软件版本和步骤。

以上是候选练习，不是已完成事项。每条记录尽量链接对应项目、提示词版本和结果图片。
