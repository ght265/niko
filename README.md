# niko · 建筑 × AI × 建模学习档案

把学习中的问题、设计过程和小实验整理成可以回看、比较、复用的记录。

## 从这里开始

1. 在 [学习记录](learning/README.md) 复制模板，或用脚本创建当天记录。
2. 在 [项目案例](projects/README.md) 选择一个真实项目，记录目标、过程和证据。
3. 将试过的 [提示词](prompts/README.md) 连同输入、工具版本和结果一起保存。
4. 在 [脚本说明](scripts/README.md) 查看可运行的小工具。

## 最小目录

| 路径 | 放什么 |
| --- | --- |
| `learning/` | 学习问题、尝试过程、结果和下一步 |
| `projects/` | 自己的设计项目及有来源的案例分析 |
| `prompts/` | 提示词、版本和对照评价 |
| `scripts/` | 可复现的小脚本及运行说明 |

当前项目：[朱村高速服务区主楼](projects/zhucun-service-area/README.md)。

## 一个简单的使用节奏

每次只推进一个小问题，例如“这个入口为什么不清楚？”或“怎样减少渲染对草模形体的改动？”。记录输入、操作和观察，再写一个下次可执行的动作。无需每天提交；积累到一项有意义的改动后再提交。

## 文件与素材

- 文档使用 Markdown；文件名优先用英文短名，日期采用 `YYYY-MM-DD`。
- 图片可以放在对应项目的 `images/` 下，用相对路径引用；提交前检查图片不含个人信息。
- 大型模型、原始视频和渲染缓存保留在自己的文件存储中，在项目页写明文件名、版本及可访问的位置。
- `.gitignore` 默认排除常见大型建模文件；确需版本管理时再单独调整策略。
- 引用案例和资料时记录作者、原始链接、访问日期及许可；不把他人的作品写成自己的成果。
- AI 输出须标注为 AI 辅助内容；设计判断、尺寸和构造需自行核验。
