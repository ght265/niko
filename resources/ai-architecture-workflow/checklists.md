# 阶段签核清单

复制到每次交付记录。每项填写通过／失败／不适用、依据、审核人、日期与复验链接。不适用需说明理由。阻断项闭环后再推进依赖阶段。

## G0–G2 资料与设计

- [ ] 原件版本、来源、许可及缺项完整登记。
- [ ] 单位、源坐标与局部变换、北向、高程和独立控制点已复测，记录容差和偏差。
- [ ] 红线与建筑轮廓分别确认，约束和设计参数有可定位依据。
- [ ] 同基线比较方案，审核功能、面积口径、公共与后勤流线和空间取舍。

## G3 模型

- [ ] SKP 副本与参数、坐标表、脚本提交可对应，同一输入可复跑。
- [ ] 检查轴向、比例、原点、楼层及关键标高，抽查尺寸、面积与边界关系。
- [ ] 检查重复构件、空组、面朝向、自交、预期实体闭合和组件／标签命名。
- [ ] 用平、立、剖和轴测对照；重大误差记录实测值、允许误差、处理人和复验结果。

## G4 可视化与归档

- [ ] D5 的材质、尺度、方位、可见性、视点和素材链接与发布 SKP 核对。
- [ ] 在独立工作副本重开 SKP、D5，核对图像和交付清单。
- [ ] 提交差异仅含授权材料，外部文件可由接收人取用，记录校验值及未关闭事项。
