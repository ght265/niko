# SketchUp Ruby 建模与校核

| 模型阶段 | 已确认输入 | 生成与验收 |
| --- | --- | --- |
| 场地 | G1 坐标表、道路边、地形和高程 | 红线与控制点对齐，抽查标高、周边方位与道路关系 |
| 体量 | 方案外轮廓、基底标高、体量高度 | 分方案保存模型，复测轮廓、标高、顶高、退界与面积口径 |
| 深化 | 分层标高、平剖、柱网、墙板、洞口表 | 每层独立组织，复测净高、开洞、轴网和关键剖面 |
| 表达 | 已通过校核的 SKP 快照、稳定材质名 | 对照原模型复查 D5 方位、尺度、构件及视点 |

项目版本经确认后逐步扩展脚本。按构件 ID 分组或复用组件，标签赋给组或组件，组内原始边面使用默认标签。统一使用局部毫米输入，在创建点与长度时通过 `.mm` 显式转换。模型生成、数据校核和人工修改分别记录。需要保留手工深化时，从生成基线另存，记录手工差异。

## 体量脚本试跑

1. 复制 [JSON 模板](templates/massing.json) 到项目授权的本地工作区。把已核准的建筑外轮廓从坐标表按顺序抄入 `footprint_mm`，每点为 `[x, y]`，末点不重复首点。填入核准的 `base_z_mm` 和正的 `height_mm`。两个引用字段须能定位到已审核的坐标实体和高度参数。填写输入修订版、审核者及“已确认”状态。
2. 打开新的空模型或可丢弃的 SKP 工作副本，退出组编辑。在 SketchUp 的 Ruby 控制台执行以下命令，换成自己的绝对路径。

   ```ruby
   load 'D:/path/to/niko/resources/ai-architecture-workflow/scripts/build_massing.rb'
   AiArchitectureMassing.build('D:/path/to/approved-massing.json')
   ```

3. 当前模板接受一个轴对齐矩形，四个顶点沿周界排列，生成单一闭合体量。斜边、孔洞、自由曲线及多体量需要扩展几何模块并单独验收。脚本检查配置字段和几何形状，资料确认仍由人完成。
4. 脚本将体量加入带输入摘要的独立组，可一次撤销。失败回滚。同一模型内存在脚本生成的顶层组时，重复运行会停止。改参后用撤销或重新打开基线副本试跑，人工复测后另存 SKP。
5. 在两份相同基线副本上用相同配置运行，核对组属性、轴向尺寸、包围盒标高、面法线与实体体积。另测空白模板、无效边序和重复运行，确认失败后原模型实体数量保持一致。

官方资料：[生成几何](https://ruby.sketchup.com/file.generating_geometry.html)、[模型操作与撤销](https://ruby.sketchup.com/Sketchup/Model.html)、[长度单位](https://ruby.sketchup.com/Length)。
