# 分阶段提示词模板

每次填写 `{项目与阶段}`、`{资料 ID、版本及获准使用的摘录}`、`{输出格式}`。通用指令：逐项标“已确认／待补充／假设”，给出资料 ID 和定位。缺数值留空，列影响、补证方法和需人工确认事项。把提示词版本、模型版本、输入索引、人工修订与复核结果写入阶段日志。

## G0–G1 场地提取

读取给定 CAD 导出及底图说明。按红线、道路、周边、地形和出入口分类列实体与图层。输出来源索引、坐标基准、局部坐标转换记录和待复测点。对截图中可见但无法度量的内容只做观察记录。标出冲突和所缺证据。

## G2 概念推演

用同一场地基线和功能要求提出两到三套空间策略。逐方案给功能邻接、观众与运营流线、平剖关系、待定参数和可证伪的假设。用相同标准比较，注明需要人工选定的取舍。保持所有已批准约束。

## G3 Ruby 脚本

根据已确认参数、坐标样表和支持的 SketchUp 版本编写脚本。先说明支持的几何类型及缺失项，再给出毫米转换、独立组、失败回滚、重复运行策略、输入版本标记和空模型试跑步骤。列出真实运行和人工测量才能验证的项目。

## G3–G4 审阅与表达

比较模型、原 CAD 和已批准平剖图。逐项给出问题等级、实体 ID、预期与实测、证据、修改动作及重验方法。为已确认模型生成镜头卡，保留实际几何、场地和材质映射，标出氛围参考。提交出图时附模型版本和图像来源。
