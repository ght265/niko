# D5 可视化与版本交付

1. 从 G3 核准的 SKP 另存发布副本。记录来源提交、参数快照、坐标变换、模型校验值及 SketchUp 版本。清理仅供核对的构件，保留稳定的材质名、局部原点和必要的视图。
2. 用当前软件组合验证一份小模型。记录 D5 与 LiveSync 版本及接入方式。正式表达可导入 SKP 快照，迭代可用 LiveSync。同步前保存 D5 工程副本，替换或同步后检查位置、比例、面朝向、材质映射、可见性和已布置资产。
3. 对城市关系、公共入口、主要公共空间、展厅和关键剖面表达分别建立镜头卡。填写镜头 ID、机位与目标、视角、时段、光照、输出尺寸、模型版本、后期处理与审核状态。AI 参考图与经核实的模型出图分别归档。
4. 按方案与阶段保留小而可追溯的 Git 提交。Git 存放脱敏文本、脚本、参数及版本清单。SKP、CAD、D5 工程、贴图和大图采用获授权的外部存储，登记版本与 SHA-256。换基线时记录影响范围并重走相关阶段门槛。发布可在审阅后用项目标签冻结同一批证据。
5. 发布包包括 SKP、D5 工程与所需素材、图像、镜头卡、参数与坐标快照、脚本版本、校核与决策记录。用独立工作副本重开 SKP 和 D5 工程，核对素材、图像和版本对应关系后登记验收。

官方参考：[D5 模型连接](https://docs.d5render.com/getting-started/d5-workflow/model-connection)、[SketchUp LiveSync 功能与版本说明](https://docs.d5render.com/workflow/sketchup/feature-introduction-or-d5-livesync-for-sketchup)。
