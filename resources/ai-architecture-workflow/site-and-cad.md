# 场地数据提取与 CAD 坐标

1. 对原件登记版本与校验值并制作工作副本。记录 CAD 源图单位、坐标参考系、轴顺序、北向、垂直基准、原点、外参和图层图例。外参、块及样条的处理要留痕。
2. 按图层与实体 ID 提取红线、道路边、出入口、周边轮廓、控制点及高程。逐项标记来源与置信范围。根据现状资料整理可达性、界面、标高关系和场地限制，分别保存观察、解释与待查问题。
3. 先完成必要的投影或基准转换。对已确认的平面笛卡尔坐标，用局部变换 `xy_local = R(theta) · (s · (xy_source − Oxy))`，`z_local = sz · (z_source − Oz)`。记录单位换算、源原点、逆时针旋转角和旋转后轴向。局部 +Z 向上，局部 +X/+Y 与正北关系须登记。经纬度先投影；高程基准变换另行记录。
4. 对照原件和独立证据，复测平面控制点、两条非平行基准线、一个已知高程点，检查比例、镜像、旋转和 Z 偏移。保留源坐标、局部坐标、逆变换残差、允许误差、工具版本和审核记录。
5. 坐标表按实体和环编号，顶点顺序稳定。闭合环通过属性标记闭合，末尾无需重复首点。核验重复点、零长边、自交、孔洞、岛、多段线闭合与面积。曲线保留原实体引用，并登记离散化误差。缺 Z 写空并阻止竖向建模。保留源坐标精度与换算过程。
6. 审核后冻结坐标表和变换记录版本。建模配置引用坐标表版本及具体实体，筛选已确认的局部毫米坐标。红线、建筑外轮廓与退界控制线分表或分实体保存，分别审核用途。

可复制的 [坐标 CSV 表头](templates/coordinates.csv)。`source_ref` 填原文件版本及实体定位，`entity_id` 填几何标识，`ring_id` 区分外环和孔，`is_closed` 明确闭合状态。一个表头对应一份变换记录。
