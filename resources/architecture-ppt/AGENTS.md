# Architecture PPT Workspace Instructions

Scope: `resources/architecture-ppt/` and subdirectories.

- Treat this folder as reusable public presentation infrastructure, not a place for private competition data.
- Read `README.md`, `02-slide-blueprints.md`, and `03-style-guide.md` before generating architectural slides.
- Prefer architectural drawings, site analysis, diagrams, and visual evidence over generic business cards or decorative imagery.
- Never fabricate dimensions, orientations, floor areas, elevations, code compliance, or construction facts.
- Do not redesign or alter source geometry when the user asks for presentation only.
- Verify rights before reusing external imagery. Keep attribution and source URLs.
- Use existing SVG furniture symbols only as schematic illustration.
- Produce an editable PowerPoint and a visual QA preview whenever tooling allows.
- Do not overwrite other parts of the repository or third-party source files.
