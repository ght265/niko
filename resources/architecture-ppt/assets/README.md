# 可复用建筑平面 SVG 符号

本目录中的 `furniture-svg/` 文件来自：

- 上游项目：https://github.com/pjm4github/FloorPlanner
- 原始路径：`assets/furnishings/`
- 上游授权说明：https://github.com/pjm4github/FloorPlanner/blob/main/assets/furnishings/LICENSE
- 授权：CC0 1.0 Universal（原作者将这些独立绘制的俯视平面家具/设备符号贡献至公有领域）
- 获取日期：2026-10-27

这些 SVG 可插入建筑学 PPT，用于**概念性平面布置、功能表达、家具类型说明**。它们不是建筑规范库，也不保证与你的项目实际家具尺寸相同；尺度和位置需要核对。

建议：
1. 在 PowerPoint 的“插入 → 图片”中选择 SVG（软件兼容时）。
2. 作为建筑平面图上的示意符号使用，保持线宽与图纸风格一致。
3. 如需导出成 PNG，保留原始 SVG 以免损失清晰度。
4. 如需其他类型，访问上游 `assets/furnishings/`，无需把全部 96 个文件复制进仓库。
