## 推荐工作流

1. 在本地克隆或更新 `ght265/niko` 仓库。
2. 将项目专属的 SU/CAD 导出图、渲染图、文本、场地资料放在 **本地项目文件夹**；公开仓库内只放能公开分享的内容。
3. 先挑选参考模板，再按照 [页面蓝图](02-slide-blueprints.md) 规划内容。
4. 在 Codex 中提供 `04-codex-prompt.md` 和项目 brief，让它生成 `.pptx`、预览 PDF，并逐页检查。
5. 手动在 PowerPoint 中复核字体、比例尺、标高、面积、设计指标和图片版权。

**限制：** 这里的外部 PPTX 是资源链接；不是已经下载到这个仓库里的二进制模板。真正入库的是本目录的文本规范和 SVG 素材。
