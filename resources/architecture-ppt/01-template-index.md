# 建筑学 PPT：精选模板与制作资源

## A. 可以下载 PPTX 的参考模板

1. **中文学位答辩模板 — slide-maker-site**
   - 文件：https://github.com/addsumtech/slides_maker-site/blob/main/templates/decks/zh/thesis-defense/template.pptx
   - 目录与预览：https://github.com/addsumtech/slides_maker-site/tree/main/templates/decks/zh/thesis-defense
   - 场景：建筑设计毕业答辩 / 课程终期评图 / 方案论证。
   - 注意：属于通用答辩版式，不是专门的建筑图纸画板，仍需用真实总平、平立剖和渲染图替换内容。

2. **中文城市文化叙事模板 — slide-maker-site（成都主题）**
   - 文件：https://github.com/addsumtech/slides_maker-site/blob/main/templates/decks/zh/chengdu/template.pptx
   - 目录与预览：https://github.com/addsumtech/slides_maker-site/tree/main/templates/decks/zh/chengdu
   - 场景：城市调研、在地文化、社区更新、场地叙事。
   - 注意：仅借鉴版式结构与视觉节奏，不要把示例文字和图片当作自己项目的资料。

3. **中文市场调研模板 — slide-maker-site**
   - 文件：https://github.com/addsumtech/slides_maker-site/blob/main/templates/decks/zh/ev-market-report/template.pptx
   - 目录与预览：https://github.com/addsumtech/slides_maker-site/tree/main/templates/decks/zh/ev-market-report
   - 场景：场地人群研究、环境数据、面积指标、使用者画像等数据类页面。

模板来源：https://github.com/addsumtech/slides_maker-site
生成工具：https://github.com/addsumtech/slides_maker （项目 README 声明 MIT；使用具体样稿中的图片、商标等仍需检查权利）

## B. 更适合建筑作品集风格的页面生成器

4. **Folio — Architectural 视觉风格**
   - 项目：https://github.com/Jorgut/folio
   - 特点：留白多、网格清晰，提供名为 Architectural 的样式，适合建筑分析与作品集视觉参考。支持多种导出格式，包括 PPTX，但需要运行生成项目；不等同于直接下载好的建筑 PPTX。
   - 应用：建筑分析图为主、文字为辅的编辑式排版。

## C. 建筑学真正有用的图纸/图形工具

5. **FloorPlanner — 可复用的平面家具矢量符号**
   - 项目：https://github.com/pjm4github/FloorPlanner
   - SVG 原始目录：https://github.com/pjm4github/FloorPlanner/tree/main/assets/furnishings
   - 特点：包含俯视的床、沙发、桌椅、汽车、卫浴等符号，素材授权为 CC0 1.0。
   - 本仓库已精选若干个 SVG 至 `assets/furniture-svg/`。适合平面布局、室内功能分析、家具布置说明。

6. **Plancraft — 建筑平面 SVG 出图工具**
   - 项目：https://github.com/pedroodb/plancraft
   - 特点：MIT 开源，用结构化文本生成含墙体、门窗和家具的建筑平面图 SVG。适用于示意方案/概念图；**不应替代正式 CAD 图纸核验**。

## 使用与授权

- 外部 PPTX **保留链接，不擅自镜像第三方整包**。下载后检查文件内第三方图片、照片、字体、品牌标志的授权。
- 本仓库复制入库的 SVG 来源与 CC0 声明见 [assets/README.md](assets/README.md)。
- 使用真实建筑案例的照片/总平面时，记录建筑师、摄影师、来源网址；公共可浏览不等于可任意商用。
- 图纸上的比例尺、朝向、标高、面积和尺寸均必须由项目原始数据核实。
