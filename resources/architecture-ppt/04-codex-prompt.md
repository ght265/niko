# 给 Codex 的建筑学 PPT 制作提示词

请以当前仓库中的 `resources/architecture-ppt/` 作为**排版规范与资源库**，根据我提供的项目原始资料，制作一份专业的建筑学方案汇报 PPT。

1. 先阅读该目录的 `README.md`、`AGENTS.md`、`02-slide-blueprints.md`、`03-style-guide.md`、`project-brief-template.md` 以及项目素材。确认实际图片与文件路径，列出资料缺口。
2. 依据汇报目的选择：方案设计 / 案例分析 / 场地调研。优先遵循项目 brief 中确定的页数、逻辑、限制。
3. 从 `01-template-index.md` 中选择适合的外部模板作为**视觉参考**。如果未下载相应 PPTX，不要假称已读取。优先复用当前本地已经实际取得的模板。
4. 视觉上以建筑图纸为主：区位、场地、体块推演、总平、平面、立面、剖面、渲染与材料细部。按现有资料排布，缺失就标明待补，不得补造图纸或结构。
5. 项目中的任何 SketchUp/CAD 模型和建筑照片必须尊重原貌。不要修改体量、轮廓、窗洞、层数、楼板标高或悬挑尺度，除非有我明确要求。
6. 只使用可核实的面积、功能、场地数据、设计指标与出处。不能确认的数字不要写成事实。
7. 在 PowerPoint 中保持标题、正文、图例可编辑；SVG 家具符号可用于示意，但不能冒充项目竣工图纸。
8. 实际生成并保存 `.pptx`，若工具环境支持，再输出预览 `.pdf` 或逐页 PNG。逐页检查文字溢出、比例、图纸裁切、图片模糊、错位、字体替换和署名。
9. 交付 `.pptx`、预览文件（若可行）、`sources.md`（图像/数据来源）和 `review-notes.md`（尚未解决的问题）。保留重要可编辑源文件。

先分析，再执行。不要只给我思路；请制作实际文件并检查。若外部工具无法安装或某张图纸不可得，说明限制并尽可能完成可用版本。
