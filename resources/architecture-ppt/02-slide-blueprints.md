# 建筑类演示页面蓝图

建筑学生 PPT 不等于商业路演：应让**图纸、模型和空间逻辑**成为主角。建议每页只有一个核心判断。

## 模板 A｜方案设计汇报（建议 10–14 页，按比赛时长裁剪）

| 页 | 主要内容 | 推荐图像类型 |
| --- | --- | --- |
| 01 | 标题、项目名称、场地、团队 | 主视觉 / 效果图 |
| 02 | 项目任务与核心设计问题 | 关键词+任务示意 |
| 03 | 场地位置、周边交通与联系 | 区位图+指北针 |
| 04 | 日照、风、交通、人流、地形等分析 | 分析图组（请标注来源） |
| 05 | 设计概念与生成逻辑 | 3–5 步体块演变 |
| 06 | 总平面与场地组织 | 总平面 + 图例 |
| 07 | 功能分区 / 面积与使用者动线 | 彩色功能分区图 |
| 08 | 平面组织 | 主要楼层平面 + 关键标注 |
| 09 | 立面与建筑表情 | 2 个主要立面 + 材料说明 |
| 10 | 剖面与空间体验 | 建筑剖面 + 关键高度 |
| 11 | 结构、材料、绿色策略 | 构造逻辑/环境策略示意 |
| 12 | 透视与场景 | 效果图 + 人的尺度 |
| 13 | 设计指标与落地性 | 面积、层数、策略与约束 |
| 14 | 核心价值与下一步 | 一句话结论 + 关键图 |

## 模板 B｜建筑案例分析（8–10 页）

封面 → 项目速览 → 场地 → 建筑师设计理念 → 体量生成 → 平面与动线 → 立面及构造 → 剖面和采光 → 优劣评估 → 自己的设计启示。

## 模板 C｜城市与场地调研（8–12 页）

研究问题 → 城市/街区脉络 → 路网与可达性 → 用地与空间形态 → 人群活动 → 日照风环境 → 空间问题 → 机会识别 → 策略建议。

## 特别适合建筑学的 6 种页面

1. **全幅图像页**：效果图、模型照片；一句标题即可。
2. **横向进程页**：体块推演、设计策略演化，保证前后模型角度一致。
3. **一主两辅页**：主平面占画面 60–70%，边侧两张分析细图。
4. **三图对照页**：原状 / 问题 / 改造策略。
5. **剖面解读页**：用短文字标注采光、空间高度、动线。
6. **指标收束页**：仅使用核验过的真实数值，说明与设计决策的关联。

## 图纸真实性

- PPT 的图是展示，不是重新设计。不要让 AI 擅自改变 SU、CAD 的几何与空间关系。
- 平/立/剖图必须采用项目源文件导出，保留真实尺度关系与方向。
- 不要让 AI 猜面积、朝向、室内净高、规范条款或图例。
