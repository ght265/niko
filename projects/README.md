## 案例目录怎么长大

每个项目从一页总览开始；随着真实资料和过程积累，再增加对应记录，不预建空目录：

- `README.md`：项目概况、当前状态、文档导航和关键文件索引。
- `design-brief.md`：设计目标、约束、已知事实与待核实问题。
- `development-log.md`：草模、方案推敲、建模和深化的版本记录。
- `ai-render-log.md`：引用通用提示词，逐次保存输入、工具、输出和几何核验。
- `milestones.md`：按阶段登记交付物和证据；没有证据的成果保持未完成。
- `TODO.md`：下一步行动及其完成依据。

只在确实需要时新增 `images/` 或子目录；大型源模型、渲染缓存和未经整理的素材放在外部存储，并在项目页登记文件名、版本和位置。不要移动或覆盖既有素材。

自己的设计记录目标、约束、方案变化与证据；分析他人案例时额外标明建筑师、项目地点、年份、原始来源和图片许可。缺失信息写“待核实”。
