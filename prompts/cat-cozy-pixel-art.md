# 猫咪照片转日系治愈像素风｜Cat Cozy Pixel Art

## 用途
上传猫咪原始照片，使用本提示词将照片转为精致的日系治愈像素艺术。**保留猫咪的身份特征和原始姿态优先于风格化。**

## 通用提示词（单张）

请以我上传的猫咪照片作为唯一的主体参考，将照片转换为精致、可爱、温暖的日系复古像素艺术（Japanese Cozy Pixel Art）。

**最高优先级：忠实保留原貌。** 严格保留猫咪的脸型、头部比例、耳朵形状及位置、眼睛颜色和形状、眼距、视线方向、鼻子、嘴巴、胡须、自然表情、毛色深浅分布、斑纹形状和位置、身体比例、姿势、动作和头部朝向。确保主人能一眼认出是原照片中的猫，不得将其替换为相似的通用卡通猫。

**像素风格：** 高品质手工像素画，参考温馨治愈系独立游戏、日系复古 RPG 与精致 2D Pixel Art。采用清晰规整的方形像素、细腻的像素级明暗层次、柔和协调的有限色盘、克制的轮廓线，营造可爱、温暖、自然、略带怀旧感的氛围。保留真实气质，不夸张五官，不使用大头娃娃比例，不添加拟人化表情。

**构图与环境：** 保留原始照片的拍摄角度、主体位置和姿势。背景可适度简化为干净、柔和的像素场景，但应保留主要环境关系和原有道具，不凭空添加其他动物或无关物品。采用温暖自然的柔光。

**画面质量：** 清晰的方形像素边缘、柔和但分明的像素明暗、细致的毛发像素层次，呈现手工逐像素绘制的质感。禁止 3D、塑料玩具质感、过度 Q 版化、模糊像素、AI 平滑插画感、额外肢体、毛色或花纹变化。

## 多张照片拼贴追加指令

当一次上传多张照片时，每张照片独立对应一个画面格子，严格按上传顺序排列。所有格子采用统一的像素密度、色彩和光影风格，保留每张照片里各自猫咪的特征、姿态、表情及关键环境元素。使用等宽白色分隔线，整体整洁协调。不得将不同照片的猫咪特征混合，不得增加、删除或重复猫咪。除非特别指定，不添加标题、标志或水印。

## 推荐设置

- 风格：Japanese Cozy Pixel Art / 2D retro game illustration
- 细节：中高像素密度，优先保留面部和毛色辨识度
- 比例：单图沿用原照片比例；拼贴根据张数选用网格
- 工作方式：上传原照片进行图生图编辑，而不是仅用文字重新生成
- 若结果不像原猫：降低风格化强度，重点重试眼睛、面部花纹、耳朵和原始姿态

> 注意：生成式图像编辑不能保证逐像素忠实还原；请对照原图检查细节。
