## 平时怎么用

1. **先说感受**：例如「安静、怀旧、神秘」，不必先知道风格名称。
2. **挑选方向**：从上述仓库找 2～3 个有参考效果图的风格。
3. **保持主体一致**：对同一张原图分别尝试不同提示词，比较构图、用光和色彩。
4. **少量微调**：每次只调整一两项，如灯光数量、镜头运动或画面饱和度。
5. **保存成功案例**：记录原图、模型、提示词、效果图和修改心得。
